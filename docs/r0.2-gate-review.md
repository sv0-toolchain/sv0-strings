# R0.2 gate review (SS-131 / SPEC §24.3)

Status: **PASS**.

Every fixture below is asserted on **both** the native C executable path and
the native VM path by `sv0-strings/scripts/test --backend=both --dir=test`
(BACKEND-009). At the time of review: **28 / 28** cases pass on both
backends.

Reproduce:

```sh
SV0_TOOLCHAIN_ROOT=<sv0-toolchain checkout> \
  sv0-strings/scripts/test --backend=both --dir=test
sv0-strings/scripts/check          # catalogs + doc fences, no toolchain
# toolchain gate (self-host loop, vm parity, allocation-failure C+VM, …):
sv0-toolchain/scripts/sv0 test
```

## Deviations carried into R0.2

Recorded in `docs/f0-deviations.md`; none changes a `TEXT-*` / `CSTR-*` /
`TOK-*` behavioural result:

- **D-4** — `Option` / `Result` are library-local, scalar-payload only; every
  `Result<_, <structured error>>` signature uses a concrete carrier
  (`Utf8Check`, `ConcatResult`, `SliceResult`, `FromUtf8Result`, `CStrResult`,
  `CStringResult`, `AppendResult`).
- **D-6** — text APIs take `string` by value (sv0 has no surface `&string`).
- **D-7** — `CStr` / `CString` have no distinct type; both are an owned
  `string` (`CStr` = NUL-free payload, `CString` = `<payload><0x00>`). The
  `borrows(...)` relations are advisory; bytes are copied at construction, so
  the no-rescan invariants (CSTR-003 / CSTR-017) hold via the travelling
  length.
- **D-8** — a `CBuffer` value **is** its `&mut [byte]` storage; the first-NUL
  state is recomputed by a bounded scan, never cached (so CSTR-016 is
  trivially satisfied). `AppendResult` inlines the `CopyReport` fields
  because a struct payload does not lower inside an enum variant.
- **D-9** — the tokenizer uses an explicit scalar cursor: `next(input,
  separators, pos: usize) -> TokenStep` instead of `&mut TokenCursor ->
  Option<Token>`; a token is the offset pair `[start, end)`. `TokenCursor`
  stays the unit of caller-held state.

Toolchain enablers landed for R0.2: **SS-U15** (collision-gated per-module
symbol mangling — `strings_bytes` / `strings_text` both export `equal` /
`find` / `rfind` / `starts_with` / `ends_with`), **SS-U16**
(`string_from_bytes` / `string_byte_view` builtins for `from_utf8` /
`as_bytes` — `as_bytes` keeps its exact `-> &[byte]` signature),
**SS-U17** (VM `SV0_STR_FAIL_AT` allocation-fault injection).
